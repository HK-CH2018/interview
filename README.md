## 面试题仓库说明

这个仓库用于整理、沉淀面试相关的知识点和问答，方便在面试前快速复习和系统化查漏补缺，主要涵盖：

- **Golang**：GMP 调度模型、goroutine 与 channel 原理、GC、内存逃逸、性能优化等
- **数据库**：MySQL 索引、事务、锁、MVCC、主从与分库分表等
- **缓存与中间件**：Redis、Kafka / MQ、分布式锁、计数器等
- **系统与架构**：CDN、K8s、容器化、分布式一致性与事务、网络协议等

### 文件结构（示例）

- `面试题.md`：综合版大纲 + 系统化问答（推荐从这里看起）
- `golang性能优化.md`：Golang 性能优化专题
- `mysql-mvcc.md`：MySQL MVCC 相关知识点
- `cdn系统总结.md`：CDN / 边缘加速体系总结
- `k8s.md`：Kubernetes 相关知识点
- `java值传递.md`：Java 值传递机制
- `DD.md`：其他补充记录/草稿

### 建议使用方式

- **面试前冲刺**：按 `面试题.md` 目录快速过一遍；遇到不熟的模块，再跳到对应专题文件。
- **平时学习**：按专题（如 `golang性能优化.md`、`mysql-mvcc.md`）深入阅读，边看边在文件中补充自己的理解和示例。
- **持续维护**：每次刷题、踩坑、看文章或做项目时，把新的思考和案例追加到对应文件中，让仓库成为你的「个人知识库」。
